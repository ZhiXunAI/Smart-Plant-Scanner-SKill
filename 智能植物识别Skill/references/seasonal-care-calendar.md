# 季节养护日历

## 春季（3-5月）

### 核心任务
- **换盆**：根系长满盆的植物换大一号盆，春季是最佳换盆期
- **施肥启动**：恢复定期施肥（2-4周一次薄肥）
- **修剪**：剪去冬季枯枝、病枝，促进新芽萌发
- **扦插繁殖**：大多数植物春季扦插成活率最高

### 浇水频率
- 逐渐增加浇水频率
- 观察盆土表面2-3cm干燥后再浇
- 早晚浇水为宜，避免正午

### 注意事项
- 倒春寒：3月注意夜间低温，喜暖植物仍需保温
- 病虫害开始活跃：定期检查叶片背面
- 出室过渡：室内越冬植物需逐步适应户外环境

## 夏季（6-8月）

### 核心任务
- **遮阳**：多数观叶植物需遮去50-70%阳光
- **通风**：高温高湿易生病，保持良好通风
- **防虫**：蚜虫、红蜘蛛、介壳虫高发期
- **控肥**：盛夏高温期减少施肥或停肥

### 浇水频率
- 蒸发量大，需增加浇水频率
- 早晚浇水，避免正午高温
- 可向叶面喷水降温增湿（多肉除外）

### 注意事项
- 暴雨排水：雨后及时倒掉托盘积水
- 空调房养护：远离出风口，注意补湿
- 休眠期植物（如仙客来、风信子）：减少浇水，阴凉处休眠

## 秋季（9-11月）

### 核心任务
- **追肥**：秋季是植物第二个生长高峰，适当追肥
- **分株繁殖**：适合分株的植物秋季操作
- **入室准备**：10月下旬起，不耐寒植物逐步移入室内
- **采种保存**：采收成熟种子，标注名称和日期

### 浇水频率
- 逐步减少浇水频率
- 秋末大幅控水，帮助植物进入休眠

### 注意事项
- 秋老虎：9月仍可能出现高温，继续遮阳
- 霜冻预警：注意天气预报，提前防护
- 落叶植物自然落叶，无需过度担忧

## 冬季（12-2月）

### 核心任务
- **保温**：大多数室内植物需5°C以上，热带植物需15°C以上
- **控水**：大幅减少浇水，盆土偏干为宜
- **停肥**：休眠期停止施肥
- **清洁叶片**：灰尘影响光合作用，定期擦拭

### 浇水频率
- 大幅减少，保持盆土微润偏干
- 中午温暖时浇水，用与室温接近的水
- 多肉植物断水或极少浇水

### 注意事项
- 暖气房：远离暖气片，注意空气湿度（可喷雾或放水盘）
- 光照不足：可移至南窗，或补光灯辅助
- 通风换气：选择温暖的中午短暂开窗

## 常见植物月度养护速查

| 月份 | 关键操作 | 特别注意 |
|------|---------|---------|
| 1月 | 保温、控水、停肥 | 防冻害、补光 |
| 2月 | 播种准备、修剪 | 月底可开始部分室内播种 |
| 3月 | 换盆、扦插、开始施肥 | 倒春寒防护 |
| 4月 | 全面施肥、出室 | 逐步适应户外 |
| 5月 | 繁殖高峰、病虫防治 | 雨季排水 |
| 6月 | 遮阳、通风、防虫 | 梅雨季节防涝 |
| 7月 | 控温、增湿、盛夏养护 | 高温休眠植物控水 |
| 8月 | 继续遮阳、防台风 | 月底可逐步恢复施肥 |
| 9月 | 追肥、秋播 | 秋老虎高温 |
| 10月 | 分株、入室准备 | 霜冻预警 |
| 11月 | 入室、控水 | 逐步减少浇水 |
| 12月 | 保温越冬 | 远离暖气、补湿 |
