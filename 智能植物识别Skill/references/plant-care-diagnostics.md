## 问题诊断流程

### 第一步：症状观察

**观察要点**：
1. **叶片症状**
   - 颜色变化：黄化、白化、褐化、黑化
   - 形态变化：卷曲、萎蔫、下垂、斑点
   - 质地变化：变薄、变厚、变脆、变软
   - 部位：新叶、老叶、整体

2. **茎部症状**
   - 颜色：变褐、变黑、出现斑点
   - 质地：变软、变脆、腐烂
   - 形态：徒长、矮化、弯曲

3. **根部症状**
   - 颜色：变黑、变褐
   - 质地：腐烂、干枯、木质化
   - 气味：发臭、霉味

4. **生长状态**
   - 生长速度：过快、过慢、停止
   - 分枝情况：稀疏、密集
   - 开花情况：不开花、开花少、花朵异常

### 第二步：环境分析

**检查项目**：
1. **光照条件**
   - 光照强度：过强、过弱、适中
   - 光照时间：过短、适中、过长
   - 光照方向：朝向、遮挡物

2. **水分管理**
   - 浇水频率：过多、过少、适中
   - 浇水量：过大、过小、适中
   - 排水情况：积水、排水不畅、良好

3. **温湿度**
   - 温度：过高、过低、波动大
   - 湿度：过干、过湿、适中

4. **土壤条件**
   - 土壤类型：粘土、沙土、壤土
   - 酸碱度：过酸、过碱、适中
   - 肥力：贫瘠、肥沃、过肥

5. **通风条件**
   - 空气流通：良好、差
   - 空气质量：污染、清洁

### 第三步：综合诊断

**诊断原则**：
1. 多症状综合分析
2. 排除法逐项排查
3. 参考植物特性
4. 结合环境因素

## 常见问题诊断

### 叶片黄化 (Leaf Yellowing)

**症状**：
- 叶片整体或部分变黄
- 新叶或老叶黄化

**原因分析**：

| 症状特征 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 老叶黄化，叶脉绿色 | 缺氮 | 施用氮肥 |
| 新叶黄化，叶脉绿色 | 缺铁 | 施用硫酸亚铁 |
| 叶片整体黄化 | 水分过多或过少 | 调整浇水频率 |
| 叶片黄化脱落 | 光照不足 | 增加光照 |
| 叶片斑点状黄化 | 病害感染 | 喷洒杀菌剂 |

### 叶片卷曲 (Leaf Curling)

**症状**：
- 叶片边缘向内卷曲
- 叶片整体卷曲

**原因分析**：

| 症状特征 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 新叶卷曲 | 水分不足 | 增加浇水 |
| 老叶卷曲 | 水分过多 | 减少浇水，改善排水 |
| 叶片向上卷曲 | 环境干燥 | 增加湿度 |
| 叶片向下卷曲 | 温度过低 | 提高温度 |

### 萎蔫 (Wilting)

**症状**：
- 叶片下垂
- 茎部弯曲

**原因分析**：

| 症状特征 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 土壤干燥萎蔫 | 缺水 | 立即浇水 |
| 土壤湿润萎蔫 | 烂根 | 停止浇水，更换土壤 |
| 高温萎蔫 | 温度过高 | 降温、通风 |
| 低温萎蔫 | 温度过低 | 保温 |

### 徒长 (Leggy Growth)

**症状**：
- 茎部细长
- 节间距变大
- 叶片稀疏

**原因分析**：
- 光照不足
- 氮肥过多
- 密度过大

**解决方案**：
- 增加光照
- 控制氮肥，增加磷钾肥
- 疏苗、修剪

### 不开花 (No Flowering)

**症状**：
- 到花期不开花
- 花芽少或脱落

**原因分析**：

| 可能原因 | 解决方案 |
|----------|----------|
| 光照不足 | 增加光照时间 |
| 营养不足 | 施用磷钾肥 |
| 氮肥过多 | 减少氮肥，增加磷钾肥 |
| 温度不适宜 | 调整温度 |
| 修剪不当 | 适时修剪 |
| 年龄不足 | 等待成熟 |

## 季节性养护调整

### 春季（3-5月）

**关键任务**：
1. **换盆换土**
   - 时机：萌芽前
   - 频率：小苗每年1次，大苗2-3年1次
   - 方法：保留部分旧土，添加新土

2. **施肥管理**
   - 肥料类型：氮肥为主，促进生长
   - 频率：每2-3周1次
   - 注意事项：薄肥勤施，避免烧根

3. **修剪整形**
   - 剪除病弱枝
   - 疏剪过密枝
   - 短截促分枝

4. **病虫害防治**
   - 预防为主
   - 定期检查
   - 及时处理

### 夏季（6-8月）

**关键任务**：
1. **遮阴降温**
   - 强光植物：适当遮阴
   - 温度控制：保持在适宜范围
   - 通风良好

2. **水分管理**
   - 增加浇水频率
   - 避免中午浇水
   - 早晚浇水为宜

3. **暂停施肥**
   - 高温休眠期停止施肥
   - 或减少施肥频率

4. **病虫害防治**
   - 重点防治病虫害高发
   - 定期喷洒杀菌剂、杀虫剂

### 秋季（9-11月）

**关键任务**：
1. **修剪准备**
   - 剪除残花
   - 疏剪过密枝
   - 准备越冬修剪

2. **施肥调整**
   - 减少氮肥
   - 增加磷钾肥
   - 促进木质化

3. **病虫害防治**
   - 清理病叶枯枝
   - 预防越冬病虫害

4. **采集种子**
   - 适时采收种子
   - 妥善保存

### 冬季（12-2月）

**关键任务**：
1. **保温防寒**
   - 移入室内（不耐寒植物）
   - 覆盖保温（耐寒植物）
   - 避免冷风直吹

2. **控水休眠**
   - 大幅减少浇水
   - 保持土壤偏干
   - 停止施肥

3. **修剪整形**
   - 落叶树休眠期修剪
   - 剪除病弱枝、交叉枝

4. **越冬管理**
   - 检查病虫害
   - 清理枯叶

## 专业养护参数

### 光照参数

**光照强度（Lux）**：
- 强光：>50000 lux（向日葵、仙人掌）
- 中光：10000-50000 lux（月季、茉莉）
- 弱光：<10000 lux（蕨类、观叶植物）

**光照时间**：
- 长日照植物：>12小时（向日葵、小麦）
- 短日照植物：<12小时（菊花、一品红）
- 日中性植物：8-16小时均可（番茄、月季）

### 水分参数

**浇水频率**（根据土壤干湿）：
- 旱生植物：土壤完全干透后浇水
- 中生植物：土壤表面干后浇水
- 湿生植物：土壤保持湿润

**浇水量**：
- 小苗：少量多次
- 大苗：量大次少
- 换盆后：暂不浇水，缓苗后再浇

**浇水方法**：
- 浸盆法：适合怕湿叶片的植物
- 沿盆边浇：避免冲刷根部
- 喷雾：增加空气湿度

### 温度参数

**温度范围**：
- 耐寒植物：-20℃-10℃（松、柏）
- 半耐寒植物：-5℃-25℃（月季、牡丹）
- 不耐寒植物：5℃-35℃（绿萝、发财树）
- 热带植物：15℃-35℃（热带兰花、天堂鸟）

**日温差**：
- 适宜温差：5-10℃
- 过大温差：易引起病害

### 土壤参数

**pH值**：
- 酸性土壤：pH 4.5-6.5（杜鹃、山茶、兰花）
- 中性土壤：pH 6.5-7.5（大多数植物）
- 碱性土壤：pH 7.5-8.5（仙人掌、玫瑰）

**土壤配方**：

| 植物类型 | 园土 | 腐叶土 | 珍珠岩/沙 | 有机肥 |
|----------|------|--------|-----------|--------|
| 观叶植物 | 2 | 2 | 1 | 适量 |
| 多肉植物 | 1 | 2 | 2 | 少量 |
| 花卉植物 | 2 | 2 | 1 | 适量 |
| 兰花 | 0 | 0 | 0 | 树皮/水苔 |

### 养分参数

**N-P-K比例**：
- 生长期：20-10-10（高氮）
- 花期：10-20-10（高磷）
- 越冬期：10-10-20（高钾）

**施肥频率**：
- 生长期：每2-3周1次
- 休眠期：停止施肥
- 花期前：增加磷钾肥

**施肥量**：
- 稀释倍数：1000-2000倍
- 施用量：根据植物大小调整

## 数据记录与分析

### 养护日志模板

```
日期：YYYY-MM-DD

植物名称：_________

【环境数据】
- 气温：____℃（最高） / ____℃（最低）
- 湿度：____%
- 光照：____小时
- 浇水：是/否，量：____ml
- 施肥：是/否，类型：______，量：____g

【植物状态】
- 叶片：____（颜色/形态）
- 茎部：____（生长情况）
- 根部：____（如可见）
- 生长速度：____（快/中/慢）
- 开花情况：____（数量/状态）

【异常情况】
- 问题：______
- 处理措施：______
- 效果：______

【备注】
- 其他观察：______
```

### 数据分析要点

1. **生长趋势分析**
   - 生长速度变化
   - 季节性规律

2. **环境与生长关系**
   - 温度与生长速度
   - 湿度与叶片状态
   - 光照与开花情况

3. **问题规律总结**
   - 常见问题时间点
   - 诱发因素

4. **养护优化建议**
   - 调整浇水频率
   - 优化施肥方案
   - 改善环境条件

## 注意事项

- 诊断需要综合考虑多个因素
- 避免过度干预，让植物自我调节
- 记录养护日志有助于长期观察
- 不同品种需要差异化对待
- 环境变化可能导致适应期
