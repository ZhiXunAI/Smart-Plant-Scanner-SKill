## 量化养护参数

### 光照管理

**量化指标**：
- **光照强度**：
  - 强光（>50000 lux）：向日葵、仙人掌
  - 中光（10000-50000 lux）：月季、茉莉
  - 弱光（<10000 lux）：蕨类、观叶植物
  
- **光照时间**：
  - 长日照植物：>12小时（向日葵）
  - 短日照植物：<12小时（菊花）
  - 日中性植物：8-16小时均可（月季）

**具体操作**：
- 摆放位置：南窗=强光，东窗=中光，北窗=弱光
- 遮阴措施：用遮阴网（30-50%遮阴率）
- 补光措施：植物生长灯（距离30-50cm，每天8-12小时）

### 水分管理

**量化指标**：
- **浇水频率**：
  - 旱生植物：土壤完全干透后浇水（间隔7-14天）
  - 中生植物：土壤表面干后浇水（间隔3-7天）
  - 湿生植物：土壤保持湿润（每天或每2天）

- **浇水量**：
  - 小盆（直径<10cm）：50-100ml/次
  - 中盆（直径10-20cm）：200-400ml/次
  - 大盆（直径>20cm）：500-1000ml/次

**具体操作**：
1. **判断是否要浇水**：
   - 方法1：手指插入土壤2-3cm，干了就浇
   - 方法2：用筷子插进土里，抽出来看是干是湿
   - 方法3：掂一下花盆重量，轻了就浇水

2. **浇水方法**：
   - **沿盆边浇**：避免冲刷根部
   - **浸盆法**：花盆放入水盆10-30分钟（适合怕湿叶片的植物）
   - **底部浇水**：从托盘浇水，植物自己吸（适合水培）

3. **浇水时机**：
   - 早晨或傍晚最佳
   - 避免中午浇水（温度太高）
   - 冬天用温水（室温左右）

### 施肥管理

**量化指标**：
- **施肥频率**：
  - 生长期：每2-3周1次
  - 休眠期：停止施肥
  - 花期前：增加磷钾肥

- **施肥量**：
  - 液体肥：按说明书稀释1000-2000倍
  - 固体肥：直径10cm花盆=3-5g/次
  - 缓释肥：按包装说明，一般2-3个月1次

**具体操作**：
1. **肥料选择**：
   - **氮肥（N）**：长叶，叶片发黄时使用
   - **磷肥（P）**：促花，花前使用
   - **钾肥（K）**：壮根，越冬前使用
   - **平衡肥（N-P-K=20-20-20）**：日常养护

2. **施肥步骤**：
   - 步骤1：土壤湿润时施肥（避免烧根）
   - 步骤2：稀释肥料（按说明书）
   - 步骤3：沿盆边浇入
   - 步骤4：施后第二天浇水一次（冲掉多余肥料）

3. **注意事项**：
   - 薄肥勤施：宁少勿多
   - 避开根系：不要直接浇在根部
   - 休眠期：停止施肥
   - 新换盆：1个月内不施肥

### 温湿度管理

**量化指标**：
- **温度范围**：
  - 耐寒植物：-20℃-10℃（松、柏）
  - 半耐寒植物：-5℃-25℃（月季、牡丹）
  - 不耐寒植物：5℃-35℃（绿萝、发财树）
  - 热带植物：15℃-35℃（热带兰花、天堂鸟）

- **湿度范围**：
  - 干燥环境：30-40%（冬季室内）
  - 适中环境：40-60%（大多数植物）
  - 湿润环境：60-80%（热带植物、蕨类）

**具体操作**：
1. **温度控制**：
   - **冬季保温**：移入室内，用保温膜包裹
   - **夏季降温**：遮阴、通风、喷雾降温
   - **日夜温差**：保持5-10℃为宜

2. **湿度控制**：
   - **增湿方法**：
     - 喷雾：早晚喷水，增加湿度
     - 托盘蓄水：托盘里放水，增加局部湿度
     - 湿毛巾：湿毛巾放在花盆附近
     - 加湿器：使用加湿器（适合多植物）
   - **降湿方法**：
     - 通风：打开窗户
     - 除湿机：使用除湿机
     - 减少浇水：适当控制浇水频率

### 土壤管理

**量化指标**：
- **pH值**：
  - 酸性土壤：pH 4.5-6.5（杜鹃、山茶、兰花）
  - 中性土壤：pH 6.5-7.5（大多数植物）
  - 碱性土壤：pH 7.5-8.5（仙人掌、玫瑰）

- **土壤配方**：
  - **观叶植物**：园土2 + 腐叶土2 + 珍珠岩1
  - **多肉植物**：园土1 + 腐叶土2 + 珍珠岩2
  - **花卉植物**：园土2 + 腐叶土2 + 珍珠岩1
  - **兰花**：树皮或水苔（不用土）

**具体操作**：
1. **配土步骤**：
   - 步骤1：准备材料（园土、腐叶土、珍珠岩）
   - 步骤2：按比例混合
   - 步骤3：消毒（阳光下暴晒或开水烫）
   - 步骤4：晾干后使用

2. **换盆步骤**：
   - 步骤1：准备新盆（比原盆大1-2号）
   - 步骤2：准备新土
   - 步骤3：轻拍花盆，取出植物
   - 步骤4：去掉部分旧土（保留1/3-1/2）
   - 步骤5：修剪烂根、长根
   - 步骤6：放入新盆，加新土
   - 步骤7：压实土壤，浇透水
   - 步骤8：放阴凉处缓苗1周

3. **pH调节**：
   - **调酸**（pH过高）：加硫磺粉、硫酸亚铁
   - **调碱**（pH过低）：加石灰粉、草木灰

## 具体操作步骤

### 修剪操作

**步骤1：准备工具**
- 工具：剪刀（锋利、消毒）
- 消毒：用酒精或开水浸泡剪刀
- 时间：春季或秋季最佳

**步骤2：选择枝条**
- 选择：病枝、弱枝、过密枝、交叉枝
- 位置：从基部剪掉（疏剪）
- 或剪掉枝条的一部分（短截）

**步骤3：修剪操作**
- 疏剪：整个枝条从基部剪掉
- 短截：剪掉枝条的1/3-1/2
- 摘心：剪掉顶芽，促进侧芽萌发

**步骤4：伤口处理**
- 大伤口：涂抹愈合剂或草木灰
- 小伤口：自然愈合即可
- 工具：再次消毒

### 扦插操作

**步骤1：准备材料**
- 扦插土：沙土、蛭石、或专门的扦插土
- 花盆：小盆（直径5-10cm）
- 覆盖物：透明塑料袋或保鲜膜

**步骤2：选择枝条**
- 选择：半木质化的枝条（不要太嫩也不要太老）
- 长度：10-15cm
- 时间：春季或秋季

**步骤3：处理枝条**
- 去叶：去掉下部的叶片，只留上部2-3片叶子
- 切口：基部斜切45度（增加生根面积）
- 激素：可选，蘸生根粉或生根水

**步骤4：扦插操作**
- 插土：插入土中深度3-5cm
- 浇水：浇透水
- 覆盖：用塑料袋或保鲜膜覆盖（保持湿度）
- 位置：放阴凉通风处

**步骤5：等待生根**
- 时间：4-6周生根
- 浇水：保持湿润但不能积水
- 通风：每天揭开覆盖物通风30分钟
- 移栽：生根后移栽到大花盆

### 分株操作

**步骤1：准备材料**
- 新盆：比原盆大1-2号
- 新土：配好的营养土
- 工具：铲子、剪刀

**步骤2：脱盆**
- 轻拍花盆，让土球松动
- 用手托住植物，倒出
- 轻轻抖掉部分旧土

**步骤3：分株**
- 观察：找到自然的分株点（有分开的根系）
- 分开：用手或工具轻轻分开
- 修剪：剪掉烂根、过长根

**步骤4：上盆**
- 填土：在新盆底部加一些土
- 放入：放入分好的植株
- 加土：加土到根颈处（根与茎的交界处）
- 压实：轻轻压实土壤
- 浇水：浇透水

**步骤5：缓苗**
- 位置：放阴凉通风处
- 时间：1-2周缓苗
- 浇水：保持湿润但不积水
- 光照：缓苗后逐渐增加光照

## 常见植物养护量表

### 月季（Rose）

| 项目 | 具体参数 |
|------|----------|
| **光照** | 全日照，每天至少6小时 |
| **温度** | 15-25℃，耐寒-15℃ |
| **浇水** | 土壤表面干后浇水，约3-5天一次 |
| **浇水量** | 中盆（15-20cm）= 300-500ml/次 |
| **施肥** | 生长期每2周施氮磷钾平衡肥 |
| **肥料** | 15-15-15或20-20-20，稀释1000倍 |
| **土壤** | pH 6.0-7.0，疏松透气 |
| **修剪** | 春季重剪，秋季轻剪 |
| **换盆** | 每2-3年春季换盆 |
| **花期前** | 增施磷钾肥（10-20-10） |

### 绿萝（Pothos）

| 项目 | 具体参数 |
|------|----------|
| **光照** | 散射光，避免强光直射 |
| **温度** | 15-25℃，不耐寒，低于10℃受冻 |
| **浇水** | 土壤表面干后浇水，约5-7天一次 |
| **浇水量** | 中盆（15cm）= 200-300ml/次 |
| **施肥** | 生长期每月施氮肥一次 |
| **肥料** | 20-10-10，稀释1500倍 |
| **土壤** | pH 6.0-7.5，疏松肥沃 |
| **湿度** | 40-60%，干燥时可喷雾 |
| **换盆** | 每1-2年春季换盆 |
| **繁殖** | 扦插，10-15cm枝条 |

### 仙人掌（Cactus）

| 项目 | 具体参数 |
|------|----------|
| **光照** | 全日照，每天8小时以上 |
| **温度** | 20-30℃，耐寒0℃ |
| **浇水** | 土壤完全干透后浇水，约7-14天一次 |
| **浇水量** | 小盆（10cm）= 50-100ml/次 |
| **施肥** | 生长期每月施稀薄肥一次 |
| **肥料** | 10-20-20（低氮高钾），稀释2000倍 |
| **土壤** | pH 7.0-8.0，排水良好 |
| **配土** | 园土1 + 腐叶土2 + 珍珠岩2 |
| **冬季** | 减少浇水，保持干燥 |
| **换盆** | 每2-3年春季换盆 |

### 发财树（Money Tree）

| 项目 | 具体参数 |
|------|----------|
| **光照** | 明亮散射光，耐阴 |
| **温度** | 20-30℃，不耐寒，低于5℃受冻 |
| **浇水** | 土壤干透浇透，约7-10天一次 |
| **浇水量** | 大盆（25-30cm）= 500-800ml/次 |
| **施肥** | 生长期每2月施氮肥一次 |
| **肥料** | 20-10-10，稀释1500倍 |
| **土壤** | pH 6.0-7.0，疏松透气 |
| **湿度** | 40-60%，干燥时可喷雾 |
| **换盆** | 每2-3年春季换盆 |
| **注意** | 怕积水，宁干勿湿 |

## 工具准备

### 基本工具

| 工具 | 用途 | 建议 |
|------|------|------|
| **浇水壶** | 浇水 | 选择长嘴，方便浇到土壤 |
| **喷壶** | 喷雾、增湿 | 选择细雾喷嘴 |
| **剪刀** | 修剪、扦插 | 选择锋利、可消毒 |
| **铲子** | 换盆、加土 | 选择合适大小 |
| **小耙子** | 松土、除草 | 选择不锈钢 |
| **pH测试仪** | 测量土壤酸碱度 | 选择电子式 |
| **温湿度计** | 测量环境温湿度 | 选择数字式 |

### 可选工具

| 工具 | 用途 | 建议 |
|------|------|------|
| **植物生长灯** | 补光 | 选择全光谱，瓦数合适 |
| **加湿器** | 增加湿度 | 选择超声波式 |
| **除湿机** | 降低湿度 | 选择适合房间大小 |
| **托盘** | 浸盆浇水 | 选择防水托盘 |
| **塑料袋** | 扦插覆盖 | 选择透明保鲜膜 |
| **生根粉** | 促进扦插生根 | 选择品牌产品 |

## 注意事项

- 量化参数要根据植物大小和环境调整
- 新买的植物要缓苗1-2周再正常养护
- 观察植物状态，及时调整养护方法
- 宁可少浇水，不要浇水过多（容易烂根）
- 施肥要薄肥勤施，避免烧根
- 定期检查病虫害，早发现早处理
