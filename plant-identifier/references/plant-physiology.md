## 光合作用

### 光合作用概述

**定义**：
光合作用是绿色植物利用光能，将二氧化碳和水转化为有机物（葡萄糖）并释放氧气的过程。

**总反应式**：
```
6CO₂ + 6H₂O + 光能 → C₆H₁₂O₆ + 6O₂
二氧化碳 + 水 + 光能 → 葡萄糖 + 氧气
```

### 光合作用的影响因素

**光照强度**：
- 光饱和点：光合速率达到最大值时的光照强度
- 光补偿点：光合速率等于呼吸速率时的光照强度
- 不同植物的光饱和点不同：
  - 阳性植物：30000-50000 lux
  - 阴性植物：10000-20000 lux
  - 耐阴植物：5000-10000 lux

**光照时间**：
- 长日照植物：需>12小时光照才能开花（如菠菜）
- 短日照植物：需<12小时光照才能开花（如菊花）
- 日中性植物：开花与日照时间无关（如月季）

**温度**：
- 最适温度：20-30℃
- 温度过低：酶活性降低，光合速率下降
- 温度过高：酶失活，光合速率下降

**二氧化碳浓度**：
- 大气CO₂浓度：约0.03%
- 增加CO₂浓度可提高光合速率
- 温室种植常用CO₂施肥

**水分**：
- 水分不足：气孔关闭，CO₂吸收减少
- 严重缺水：光合作用停止

### 光合作用的类型

**C3植物**：
- 例子：水稻、小麦、大豆
- 特点：首次光合产物是3-磷酸甘油酸
- 光合效率：较低

**C4植物**：
- 例子：玉米、甘蔗、高粱
- 特点：首次光合产物是草酰乙酸（C4化合物）
- 光合效率：较高，适合高温干旱环境

**CAM植物（景天酸代谢）**：
- 例子：仙人掌、景天科植物
- 特点：夜间吸收CO₂，白天进行光合作用
- 光合效率：较低，但节水能力强

### 光合作用与养护

**光照管理**：
- 了解植物的光照需求
- 提供充足但不过强的光照
- 合理利用反射光增强光照

**温度管理**：
- 保持适宜温度
- 避免温度过高或过低
- 注意日夜温差

**CO₂管理**：
- 通风换气，补充CO₂
- 温室中可进行CO₂施肥
- 种植密度不宜过大

## 呼吸作用

### 呼吸作用概述

**定义**：
呼吸作用是植物细胞分解有机物，释放能量供生命活动需要的过程。

**总反应式**：
```
C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 能量
葡萄糖 + 氧气 → 二氧化碳 + 水 + 能量
```

### 呼吸作用的类型

**有氧呼吸**：
- 条件：有氧气存在
- 产物：CO₂ + H₂O + 大量能量
- 效率：高

**无氧呼吸（发酵）**：
- 条件：无氧气存在
- 产物：酒精 + CO₂ + 少量能量（或乳酸）
- 效率：低
- 例子：水涝时根系进行无氧呼吸

### 呼吸作用的影响因素

**温度**：
- 温度升高，呼吸速率加快
- 最适温度：25-35℃
- 温度过高或过低，呼吸速率下降

**氧气浓度**：
- 氧气浓度升高，呼吸速率加快
- 氧气浓度降低，呼吸速率下降
- 氧气缺乏时进行无氧呼吸

**水分**：
- 适量水分促进呼吸作用
- 水分过多：根系缺氧，无氧呼吸

### 呼吸作用与养护

**通风管理**：
- 保持良好通风，提供充足氧气
- 避免密植，改善空气流通
- 温室注意CO₂和O₂平衡

**浇水管理**：
- 避免积水，防止根系缺氧
- 合理排水，促进有氧呼吸

## 蒸腾作用

### 蒸腾作用概述

**定义**：
蒸腾作用是植物体内的水分通过气孔以水蒸气形式散失到大气中的过程。

### 蒸腾作用的意义

**降温作用**：
- 水分蒸发带走热量，降低叶片温度

**运输作用**：
- 产生蒸腾拉力，促进水分和矿质元素的向上运输

**维持膨压**：
- 保持细胞膨压，维持植物形态

**气体交换**：
- 气孔开放，促进O₂和CO₂的交换

### 影响蒸腾作用的因素

**光照强度**：
- 光照增强，蒸腾作用加强
- 光照促进气孔开放

**温度**：
- 温度升高，蒸腾作用加强
- 高温增加叶片内部水汽压

**湿度**：
- 空气湿度增加，蒸腾作用减弱
- 干燥环境蒸腾作用加强

**风速**：
- 风速增加，蒸腾作用加强
- 风速带走叶片表面水汽

**土壤水分**：
- 土壤水分充足，蒸腾作用加强
- 土壤干旱，气孔关闭，蒸腾作用减弱

### 蒸腾作用与养护

**浇水管理**：
- 根据蒸腾速率调整浇水频率
- 高温干燥时增加浇水
- 高湿环境减少浇水

**湿度管理**：
- 保持适宜湿度
- 旱生植物需低湿度
- 喜湿植物需高湿度

**通风管理**：
- 保持良好通风
- 避免强风直射
- 适当遮阴降低蒸腾

## 水分吸收与运输

### 水分吸收

**吸收部位**：
- 根系：根毛是主要吸收部位
- 茎叶：少量吸收（如气生根）

**吸收动力**：
- 根压：根系主动吸收水分产生的压力
- 蒸腾拉力：蒸腾作用产生的拉力（主要动力）

**影响吸收的因素**：
- 土壤水分：土壤干旱吸收困难
- 土壤温度：温度过低根系活性下降
- 土壤通气：缺氧影响根系呼吸和吸收
- 土壤盐分：盐分过高导致生理干旱

### 水分运输

**运输途径**：
- 木质部导管：水分向上运输的主要通道
- 胞间连丝：细胞间水分交换

**运输机制**：
- 蒸腾拉力：主要动力
- 毛细作用：辅助作用
- 根压：辅助作用

## 矿质营养

### 必需元素

**大量元素**：
- 氮(N)、磷(P)、钾(K)：需要量最大
- 钙(Ca)、镁(Mg)、硫(S)：需要量中等

**微量元素**：
- 铁(Fe)、锰(Mn)、锌(Zn)、铜(Cu)、硼(B)、钼(Mo)、氯(Cl)、镍(Ni)：需要量极少

### 主要元素的作用

**氮(N)**：
- 作用：组成蛋白质、核酸、叶绿素
- 缺乏症状：老叶黄化、植株矮小
- 过量症状：徒长、抗病性下降

**磷(P)**：
- 作用：组成ATP、核酸、磷脂
- 缺乏症状：叶片暗绿、开花不良
- 过量症状：影响微量元素吸收

**钾(K)**：
- 作用：调节渗透压、促进物质运输
- 缺乏症状：叶缘焦枯、抗病性下降
- 过量症状：影响镁、钙吸收

**钙(Ca)**：
- 作用：组成细胞壁、维持细胞结构
- 缺乏症状：顶芽死亡、果实腐烂
- 过量症状：影响其他元素吸收

**镁(Mg)**：
- 作用：组成叶绿素、激活酶
- 缺乏症状：老叶叶脉间黄化
- 过量症状：影响钾吸收

**铁(Fe)**：
- 作用：组成细胞色素、参与光合作用
- 缺乏症状：新叶黄化（缺铁性黄化病）
- 过量症状：影响磷吸收

### 养分吸收的影响因素

**土壤pH**：
- pH 6.5-7.0：大多数元素吸收良好
- pH过低：铝、锰毒害
- pH过高：铁、锰缺乏

**土壤通气**：
- 通气良好：根系活跃，吸收增强
- 通气不良：根系缺氧，吸收减弱

**土壤温度**：
- 温度适宜：吸收增强
- 温度过低：根系活性下降

**水分**：
- 水分适量：养分溶解，便于吸收
- 水分过多：氧气不足，吸收受阻
- 水分过少：养分不溶解，吸收困难

### 养分与养护

**施肥原则**：
- 薄肥勤施：少量多次，避免一次施用过多
- 对症施肥：根据植物需求选择肥料
- 适时施肥：生长期多施，休眠期少施或不施

**施肥方法**：
- 土壤施肥：根部施肥，主要方法
- 叶面施肥：快速补充，辅助方法
- 深施：深根植物
- 浅施：浅根植物

## 植物激素

### 生长素类

**吲哚乙酸(IAA)**：
- 作用：促进生长、促进插条生根、抑制侧芽
- 应用：扦插生根、顶端优势

### 赤霉素类

**赤霉素(GA)**：
- 作用：促进茎伸长、打破休眠、促进开花
- 应用：促进抽薹、种子发芽

### 细胞分裂素类

**玉米素(zeatin)**：
- 作用：促进细胞分裂、延缓衰老
- 应用：保绿、保鲜

### 脱落酸

**脱落酸(ABA)**：
- 作用：促进脱落、促进休眠、关闭气孔
- 应用：促进落叶、提高抗逆性

### 乙烯

**乙烯**：
- 作用：促进果实成熟、促进衰老
- 应用：果实催熟

### 生长抑制剂

**矮壮素(CCC)**：
- 作用：抑制茎伸长，促进茎增粗
- 应用：防止徒长

## 生长与发育

### 生长类型

**一年生植物**：
- 生命周期：一年
- 例子：水稻、玉米、向日葵

**二年生植物**：
- 生命周期：两年
- 第一年：营养生长
- 第二年：生殖生长
- 例子：胡萝卜、白菜

**多年生植物**：
- 生命周期：多年
- 例子：月季、牡丹、竹

### 发育阶段

**种子萌发期**：
- 条件：适宜温度、水分、氧气
- 过程：吸水膨胀、胚根生长、胚芽生长

**幼苗期**：
- 特征：根系发育、真叶展开
- 养护：保持湿润、适当遮阴

**生长期**：
- 特征：快速生长、叶片增多
- 养护：充足光照、适量水肥

**开花期**：
- 特征：花蕾形成、花朵开放
- 养护：增加磷钾肥、避免干旱

**结果期**：
- 特征：果实发育、种子成熟
- 养护：充足光照、适量浇水

**休眠期**：
- 特征：生长停止、叶片脱落
- 养护：减少浇水、停止施肥
